Le TypeScript c'est du javascript typé ayant pour extension .ts et .tsx quand il est utilisé dans du React. Il permet de donner des types aux attributs afin de détecter les erreurs d'exécution du programme. TypeScript permet aussi de créer des structures de données avec type ou interface tels que des objets et ses propres types de variables, de définir des propriétés optionnelles avec ?. TypeScript offre la possibilité d'utiliser les génériques pour créer du code réutilisable et fortement typé, afin d'éviter les répétitions dans le code. TypeScript est basé sur JavaScript et reprend donc sa syntaxe et ses principales fonctionnalités ; il ne remplace pas JavaScript, mais ajoute principalement un système de typage permettant de rendre le code plus sûr et plus prévisible. Contrairement à JavaScript, où les types sont principalement vérifiés pendant l'exécution, TypeScript permet de détecter de nombreuses erreurs avant l'exécution grâce à la vérification des types. Le code TypeScript est ensuite transformé en JavaScript afin de pouvoir être exécuté par le navigateur ou par Node.js. Avec React, TypeScript permet de typer les composants, les props, les événements, les états useState, les fonctions et les données manipulées dans l'interface.
