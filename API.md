### API et intégration dans TaskFlow

Une API (Application Programming Interface) permet à deux applications ou services de communiquer entre eux. Elle permet notamment de récupérer, envoyer, modifier ou supprimer des données sans avoir à gérer directement le fonctionnement interne du service utilisé. Les API permettent de gagner du temps, de réutiliser des services existants et de connecter facilement plusieurs systèmes.

J’ai étudié les API REST et SOAP, ainsi que la différence entre les API publiques, accessibles à des applications externes, et les API privées, utilisées dans un environnement contrôlé. Dans TaskFlow, j’ai mis ces notions en pratique avec une API REST créée avec Next.js. J’ai intégré Firebase Authentication pour gérer les utilisateurs et Firestore pour stocker les tâches. Les routes `/api/tasks` permettent de créer, récupérer, modifier et supprimer les tâches. J’ai aussi utilisé Firebase Admin pour vérifier le token de l’utilisateur avant d’autoriser les différentes actions.
